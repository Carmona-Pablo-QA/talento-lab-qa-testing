# Talento Lab - QA Manual Testing

Proyecto de QA Manual realizado como proyecto final de formación en Testing QA.

El objetivo fue analizar y testear funcionalmente el módulo de registro de usuarios de la aplicación **Talento Lab**, documentando el proceso completo de pruebas y los defectos encontrados.

## 👤 Rol

**QA Manual Tester**

Responsabilidades principales:

- Análisis de requerimientos e historias de usuario
- Diseño de casos de prueba
- Ejecución de pruebas funcionales
- Testing negativo
- Testing responsive
- Reporte y documentación de bugs
- Registro de evidencias
- Seguimiento de incidencias
- Elaboración de métricas y reporte final

## 🛠️ Herramientas y metodología

- Jira
- Zephyr
- Casos de prueba
- Bug Reporting
- Testing funcional
- Testing responsive
- Metodología Agile

## 🧪 Alcance del testing

Se realizaron pruebas sobre el flujo de registro de usuarios, verificando aspectos como:

- Campos obligatorios
- Validaciones de email
- Validaciones de contraseña
- Confirmación de contraseña
- Carga de CV
- Mensajes de error
- Comportamiento del formulario
- Visualización en diferentes resoluciones

## 📊 Resultados

Se diseñaron y ejecutaron **10 casos de prueba**.

| Resultado | Cantidad |
|---|---:|
| Total ejecutados | 10 |
| PASS | 4 |
| FAIL | 6 |
| Cobertura de ejecución | 100% |

Los resultados permitieron identificar diferentes defectos funcionales y problemas de usabilidad antes de una posible liberación del producto.

## 🐞 Bug Reporting

Los defectos encontrados fueron documentados incluyendo:

- Descripción del problema
- Pasos para reproducir
- Resultado esperado
- Resultado obtenido
- Prioridad
- Evidencias
- Seguimiento en Jira

Entre los hallazgos se detectaron problemas relacionados con validaciones, mensajes al usuario y comportamiento responsive.

## 📱 Testing Responsive

La aplicación también fue evaluada en diferentes resoluciones:

- Desktop: 1920 × 1080
- Tablet: 768 × 1024
- Mobile: 390 × 844

Se identificaron incidencias de visualización y usabilidad en dispositivos con menor resolución.
